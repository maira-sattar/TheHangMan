# Hangman Game

A classic, interactive browser-based Hangman game built using HTML, CSS, and JavaScript.

## 🚀 Built With

* **HTML** - Structure and markup
* **CSS** - Styling, layout, and responsiveness
* **JavaScript** - Game logic, word guessing, and interactivity

## ✨ Features

* **Interactive Gameplay:** Guess the secret word letter by letter right in your web browser.
* **Dynamic Feedback:** Real-time updates as you select letters and reveal parts of the word.
* **Responsive Design:** Clean, modern user interface styled with custom CSS.
